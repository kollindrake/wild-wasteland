# Character Progression

Character progression rules of the **2d10 Engine**.

Only Character Levels and Ranks are approved. Everything else about progression is unresolved (see [Unresolved Progression Mechanics](#unresolved-progression-mechanics)).

## Character Levels and Ranks

- **Rule ID:** PROG-001
- **Status:** Canonical (approved by the project owner 2026-11-25, [DEC-0005](../design/design-decisions.md#dec-0005--character-levels-and-ranks))
- **Category:** Character Progression
- **Last Revised:** 2026-11-25

### Purpose

Gives every character a Character Level that measures overall advancement, and groups those levels into five Ranks that mark distinct stages of progression.

### Rule

1. Every character has a **Character Level**.
2. The minimum Character Level is **1**. The maximum Character Level is **20**.
3. Character progression is divided into five **Ranks**. Each Rank covers four consecutive Character Levels.
4. A character's Rank is determined by their current Character Level, using the table below.

| Rank | Name | Character Levels |
|---:|---|:---:|
| 1 | **Drifter** | 1–4 |
| 2 | **Survivor** | 5–8 |
| 3 | **Veteran** | 9–12 |
| 4 | **Renowned** | 13–16 |
| 5 | **Legend** | 17–20 |

### Requirements

None beyond having a Character Level. How a character gains Character Levels is not yet established.

### Resolution

**Rank advancement.** A character automatically advances to a Rank upon reaching that Rank's minimum Character Level:

| Rank | Reached at Character Level |
|---:|:---:|
| 1 — Drifter | 1 |
| 2 — Survivor | 5 |
| 3 — Veteran | 9 |
| 4 — Renowned | 13 |
| 5 — Legend | 17 |

Rank advancement is determined exclusively by Character Level. There is no separate Rank advancement system, cost, or check.

### Exceptions

None established.

### Mechanical Interactions

None established. No rule currently grants a benefit, imposes a restriction, or applies a modifier based on Character Level or Rank.

### Example

A character at Character Level 8 is Rank 2 (Survivor). On reaching Character Level 9, they become Rank 3 (Veteran) immediately, with no further step.

### Balance Considerations

None to assess yet. Levels and Ranks carry no mechanical effects until benefits, restrictions, or modifiers are approved.

## Unresolved Progression Mechanics

- **Status:** Unresolved ([UQ-0007](../design/unresolved-questions.md#uq-0007--progression-mechanics-beyond-levels-and-ranks))

The project owner has stated that the following are **not established** and must not be defined without explicit approval:

- Experience Points and advancement requirements
- Rank-specific benefits
- Rank-based restrictions
- Attribute advancement
- Skill advancement
- Perk prerequisites
- Rank-based equipment restrictions
- Rank-based mechanical modifiers
