# System Documentation Structure
## Tags
The Fallout 2d10 System Documentation uses two tag namespaces to classify system documentation: `rules` and `status`.
### Rules
The rules namespace identifies documents that define, explain, or describe game mechanics. This is the primary classification system.

- rules/core
	- rules/core/check
	- rules/core/glossary
- rules/characters
	- rules/characters/mutation
	- rules/characters/race
	- rules/characters/background
	- rules/characters/perk
	- rules/characters/flaw
	- rules/characters/trait
	- rules/characters/advancement
- rules/combat
	- rules/combat/initiative
- rules/equipment
	- rules/equipment/vehicles
	- rules/equipment/economy
- rules/gamemaster
	- rules/gamemaster/rng
- rules/subsystem
	- rules/subsystem/survival

	- rules/subsystem/chase

	- rules/subsystem/allies
	- rules/subsystem/exploration
	- rules/subsystem/networking
	- rules/subsystem/faction
	- rules/subsystem/downtime
### Status
The `status` namespace identifies the current development stage of a document.

Each document should have **one status** at a time.
- status/idea: Early concept without established mechanics.
- status/draft: Mechanics are actively being written or expanded.
- status/review: A completed draft awaiting evaluation for clarity, consistency, or balance.
- status/playtest: A rule currently being tested during gameplay.
- status/final: A rule considered complete and published in current ruleset.
- status/archive: Historical material no longer in active development.
