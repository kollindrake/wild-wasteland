# Wild Wasteland

Wild Wasteland is a tabletop role-playing game (TTRPG) rules system. The imported rules use the working title **Fallout 2d10**; checks are rolled on two ten-sided dice.

This repository is the source of truth for the system. All content is Markdown.

## Start here

- [CLAUDE.md](CLAUDE.md): the project owner's agent rules and operating guidelines (authoritative).
- [AGENTS.md](AGENTS.md): short shared instructions for any assistant working in this repository.
- [project/HANDOFF.md](project/HANDOFF.md): current project context, open questions, and next steps.
- [CHANGELOG.md](CHANGELOG.md): revision history.

## Layout

| Folder | Contents |
| --- | --- |
| [`rules/`](rules/INDEX.md) | Rules text. Everything currently there is imported Draft material awaiting owner confirmation. |
| [`design/`](design/INDEX.md) | Design decisions, probability analysis, unresolved questions. |
| [`project/`](project/INDEX.md) | Status, development log, roadmap, tasks, known issues, handoff. |

`reference/` and `playtesting/` from the planned structure in CLAUDE.md §5 do not exist yet, because there is no real content for them. They will be created when there is.
