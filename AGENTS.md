# Agent Instructions

Shared instructions for every assistant working on Wild Wasteland (Claude as primary rules agent, ChatGPT as read-only observer, or any other).

1. **Read [CLAUDE.md](CLAUDE.md) first.** It is the project owner's full rule set and overrides anything here.
2. **Then read [project/HANDOFF.md](project/HANDOFF.md)** for current state, and [design/UNRESOLVED_QUESTIONS.md](design/UNRESOLVED_QUESTIONS.md) and [project/KNOWN_ISSUES.md](project/KNOWN_ISSUES.md) before touching rules.
3. **Scope:** tabletop rules only. No software, scripts, websites, campaign settings, or narrative content.
4. **Authority:** the project owner (Kollin) decides what is canonical. Never invent, promote, or silently change mechanics. Put suggestions in `design/` as proposals, not in `rules/`.
5. **Status:** every rules file carries a status line using the statuses in CLAUDE.md §6.
6. **Format:** GitHub-compatible Markdown only.
7. **Records:** after a significant change, update `CHANGELOG.md`, `project/DEVELOPMENT_LOG.md`, and `project/HANDOFF.md`.
8. **Observers** (ChatGPT) read and report only; they do not modify the repository without explicit authorization.
9. **Never commit** credentials, secrets, or personal data.
